# Código de Conduta

Este é um projeto pessoal, mantido por uma única pessoa. Ainda assim, se você abrir uma issue, comentar em uma PR ou interagir de qualquer forma neste repositório, espera-se um mínimo de respeito:

- Seja educado e direto. Críticas construtivas ao código são bem-vindas; ataques pessoais não.
- Sem discurso de ódio, assédio ou linguagem discriminatória, sob nenhuma circunstância.
- Mantenha as discussões relacionadas ao projeto.

Comportamento abusivo pode resultar no bloqueio da conta e na remoção dos comentários, a critério do mantenedor.
